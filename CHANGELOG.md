# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Unreleased

## 0.0.1 - unreleased

First public release. Nothing is published yet; the date is set on the day it is.

### Changed

- **The story and the docs (round 12, r3-docs-gates).** The README is about 90 lines and starts from the idea: a live agent, optional context, context built as the meeting goes, cards from what happens. "Moment" is explained once. Live reading is the default and Classic is the rollback, in the README, the Getting started guide and the User guide. Getting started starts with "Install the app" and "Try a practice call"; the developer walk-through moved to the Development guide. Every number in the docs says whether it is scripted or recorded; there is no recorded run of live reading yet. New: ADRs 56 to 62 (default engine and the floor, precision and learning, fit by construction, speaker epoch, early start, ship thresholds and the blind split, scripted against recorded), ADRs 63 to 66 (one memory, modes, lookup, measured budgets), the morning kit page `docs/MORNING-KIT.md`, a Custom modes section in the pack format, and a full ADR index. The ROADMAP list of unverified things is now the real one.

### Fixed

- **Final pass (round 12).** On a very long call (about 40,000 words) the memory loop and the must-cover check stopped reading new lines after the transcript dropped its middle; they now keep a call-wide cursor. A speech socket that stays open but hears nothing back for 20 s while audio is sent (Deepgram, after sleep or a network change) is reopened. A retry of the first STT open starts at the primary provider again, and a fallback taken at open fails back after a minute. The tray waits up to 300 ms for the last stdout lines after the engine exits, so a call that saved is not reported as crashed; Stop and delete works after a plain Stop; the practice call's temp folder is removed when the spawn fails. Test keys are placeholders, so tests and the eval run without a keys file. The user guide describes the live-reading window, and the screenshots in `docs/ux/` were retaken. See ADR 67.
- **Reliability round 3.** Speaker numbers restart with each STT connection, so a reconnect, provider switch or failback never gives one person another person's label (a voice joins an earlier person only when both get the same name). Audio is kept in the ring whenever the STT socket is not open, also before the first connect. Shutdown has one deadline counted from its start, always under the tray's 20 s kill. The mic watch starts after the mic does, and each audio start has an 8 s timeout. Stop during a start leaves no ffmpeg. Dialogs are async, and quit kills a stuck engine group at once. Soniox keeps pending final words on a reopen. Failback credits audio and errors to the right provider. Per-call maps and the transcript are capped. `log.write` survives circular and BigInt rows. The control socket no longer changes the process umask, and refused starts do not use the rate budget.
- **Answer window (round 12).** The "AI paused" pill never showed; it does now. The window no longer keeps a second, unbounded buffer of card rows before the page is ready (the capped backlog replays them). On exit the window clears its timers and screen listeners.
- **Reliability round 2.** An audio source that hangs after a restart is rebuilt until frames flow, and a wake no longer flashes the red bar. Stop writes the call record first, so a slow close cannot lose it, and a stray error never ends a stopping call early. Stop pressed during a slow start is read at once. STT events are wired before the sockets open. The call goes back to the primary STT provider after a stable minute, a wake leaves healthy sockets alone, and a failing first open no longer opens two fallback sockets. The tray controller caps its stdout buffer, parses a last line without a newline, and recovers from a failed spawn.

### Added

- **Round 3 checks (r3-docs-gates).** Five end-to-end files in `src/e2e/r3-gates-*.test.ts`, all on the virtual clock with fake streams, no network: speaker numbers across a faked reconnect and a faked provider switch through the real channel, wiring, ingest and speaker book; no audio lost before the first open (a black-hole open and an open that times out); early-start latency (scripted, median 1500 to 1000 ms after the end of speech); a golden-dev replay with the AI paused (no model call, 60 of 68 answer moments get a card); and a 3-hour soak with a reconnect storm, a provider switch, a slow model, a 529 storm, a dialog nobody answers and a quit while the engine is wedged (fake child). All scripted. `qa/eval-baseline.json` and `qa/budgets.json` were re-recorded on the merged code.
- **Ship thresholds and a blind split (round 12, verify-ship).** `pnpm eval:ship` (or `pnpm eval --ship`) judges 16 absolute lines from `qa/ship.json`, pass or FAIL each, apart from the regression baseline; recorded-only lines print `n/a (scripted)`. Four bad models must fail the gate. A third held-out split `test-c` is read only by `--final --ship` (it is not truly blind, see ADR 61). A scheduler fuzz test (500 fixed seeds) found and fixed three bugs: a repeated card got through when an older record had an older memory version; the observer could ask twice for one line; two chips can still show for one line (reported, not fixed). Latency tests use a committed delay distribution (assumed until recorded). Two source greps became lint rules.
- **Precision and learning (round 12, moments-precision).** A reply can say `CONF: low`; a low-confidence card or one with VALUE 1 is a chip and never takes the hero seat. `LABEL` is always asked for and never made from the first words. A SAY has 12 words in the prompt, 14 at most in the parser; a longer observer card gets one retry, a longer direct card is cut at a clause end with `fit: false`. The same words again inside 20 seconds are a repeat. "Fewer like this" raises the bar for that kind at once, and after 3 negative ratings on 2 calls the bar rises by one in later calls (`learn.json`: counts only). Scripted dev run: precision 70.5 to 79.9 percent, duplicates 7.6 to 1.0 percent, recall 84.9 to 84.6.
- **A floor without AI, and early start (round 12, moments-floor).** With the AI paused, a language-neutral floor (speech-to-text "?", digits and money, a stall-tier bank card, a bank score, your name, short sentence shape) decides where a card helps. The bank scorer adds word tokens beside 3-grams. Follow-up openers moved to `lang/`; the hosting topic logic sits behind a profile hook. New setting `moments.earlyStart` (off): a stable partial starts the direct call before the final. `gate.ts` is now `stt-gate.ts` (a one-line re-export stays). A final over 2000 characters keeps its text and word list in step.
- **A calmer main window (round 12, app-ux).** Start is off with a plain reason and a Fix it button when a key is missing or the readiness check failed. The practice call sits beside Start until a first call is saved. Settings has five tabs; Classic and Live reading appear only in Advanced. A prepared meeting shows **What Wingman knows** once before it starts (untick or edit lines, a conflict warning, Start without review). The call kind is shown as a guess. The Follow-up tab is now Summary, with an Open summary button on the ended banner; the permanent "cards to rate" pill is gone. The note window follows the interface language and the dark theme. No environment variable names reach the user. Contrast fixes in the light theme.

- **Answer window v3 (round 12, r3-cards-overlay).** The hero card shows its line in full; a long line clamps to three lines with More, and nothing is cut with an ellipsis. Chips show the label or the kind word (never the first words of the line), one kind mark, one bold unseen dot and an age; fact chips read "label: value". The transcript is one small line, so the card is the largest thing. After 3 minutes a card fades and says "about: ..."; after 6 minutes an answer or prompt becomes a chip. Open, Promises, Cover and Earlier cards are one Context button with a count, and Catch me up is the only primary button. Card buttons show on hover, focus or after a minute; new "Fewer like this" (rating `fewer`). Keyboard model (Enter, Esc, P, 1, 2) with a focus ring; screen readers hear only a Check and the first card after a pause; a new Check flashes amber. Key hints hide after the first 3 cards. Ages read correctly in Hebrew and English.
- **The morning run and more ways to measure (round 12, verify-record).** `pnpm morning --cap 5` records the dev meetings, the memory eval, the judgement set and the held-out splits in one run with one cost cap, asks for a yes before each held-out read, writes `qa/recorded-baseline.json` and a one-page `qa/out/morning.md`, and checks the simulated cost against the recorded usage (15 percent). `pnpm replay` re-runs a real call through the moment role with another prompt and shows kept, new and gone cards. A 120-case judgement set (`pnpm eval:judge`, English and Hebrew) scores the moment role per kind; the memory eval grew from 12 to 24 calls with F1 per class and an objections class. Cassette entries carry a prompt hash; a changed prompt is reported as stale, not as a miss; `pnpm cassette:status` prints coverage. Nothing here changes what the app does.
- **More ways to give context, and memory across calls (round 12).** The Meeting context box takes pasted text, dropped files (.txt, .md, .docx, .eml, .pdf, .ics), a web address, and "use my next calendar event" (setting `context.calendarUrl`, a private .ics address; repeating meetings count at their next date; Wingman shows the meeting and asks before using it). Web pages are read over https only, with an 8 second limit and 1 MB cap; private, loopback and link-local addresses (also after a redirect) are refused. "Wingman understood: ..." shows under the box, and each fact in "What Wingman knows" has a source line. A new call can start with up to 5 "Last time" facts about people on the roster (setting `context.pastCalls`, local, no model call), and the first mention of such a person can show one Fact card. The Review tab shows a moment report and coaching numbers. No new model call and no new dependency.
- **Release gates (round 12, gates).** `pnpm eval` now gates cost and latency per role from `qa/budgets.json` (+20 percent fails), prints the memory eval, and reports the held-out splits `test` and `test-b` side by side with `--final`. `pnpm eval --cassette <file>` plays a recording of the real model; `scripts/cassette-record.ts --judge` records judge verdicts too. A fault-injection soak (`src/e2e/r2-soak.test.ts`) covers a hung audio respawn, a display unplug, a dead STT socket, a slow model, a 529 storm and a stray error at Stop. `scripts/snapshot-check.sh` runs the overlay and dashboard picture checks in English and Hebrew without showing a window.
- Test `r2-wordlist-guard`: no new word list (array, Set or word regex) outside `src/lang/`. Existing lists are counted per file and cannot grow.

- **Context and modes (round 12, r3-context-modes).** The call frame no longer has its own model call: the call memory is the one place that learns what a call is about, and the list of call kinds lives in one file (`session/types.ts`). The question path without a memory loop (AI paused, legacy engine) reads the call memory and a plain tail cut by size, not the last 12 lines. A name the speech-to-text garbles is matched to a roster name by edit distance (Hebrew letters are folded, no word list); a new name that matches nobody wakes the updater once, with the roster list. After a compaction a local check puts back any open question, open promise or unhandled objection that was pushed out (event `compact.lost`). When the prompt must shrink, the summary detail goes first and the best background chunk stays longer than the raw tail. Cards carry the chunk ids with the file name they came from. `wingman doctor` and the cost report print input, cache read, cache write, hit share and USD an hour per role, say when block A is under the model's cache minimum, and warn once per role per call when the token estimate is off by more than 25 percent. `context/calibration.ts` and `scripts/calibrate-tokens.ts` fit the estimate from real usage rows (the committed numbers are not fitted yet). The tail cache stays off: the simulator shows no role above a 10 percent gain. Modes: you can choose the call mode (`kindLocked`: the memory updater cannot change it), the control command `mode <kind|id|auto>` works through the control socket, a prepared meeting keeps its mode, and `modes.yaml` in your pack adds up to 6 modes of your own (600 characters each). The memory view carries `kind`, `kindLocked` and `modeId`. A saved call with a "Last time" fact no longer fails the `session.json` check.

- **Context quality (round 12).** The last pass of the call memory now runs at Stop, so the last seconds of a call are in the wrap-up. The memory wakes on a digit, a question mark, a long line, a pause or a new word after a speaker change, with no word list and no capital letters (works the same in Hebrew). A topic change makes the observer look at the call at once, and your ratings tune the observer. A nearly full list wakes the compactor. The prompt cache layout follows how often each block changes (cost per hour on the test calls fell from $0.061 to $0.050); usage rows carry `cache_read`, `cache_write` and the estimate drift; `wingman doctor` prints a cache report. New: `pnpm eval:memory` scores the final memory of 12 labelled calls (6 English, 6 Hebrew) with a null and a copy-all control.
- **v2 gate tests.** Six e2e files for the whole v2 engine: latency budgets, cost per role against the plan table, golden dev meetings with null and noise controls, a failure matrix (model down, STT down, both, 429 storm, corrupt `session.json`, kill during a save, clock jump, huge brief), a 3-hour soak with faults, and prompt snapshots for every role. See `docs/DEVELOPMENT.md`.
- **Ask the call, Catch me up, pre-meeting digest.** Ctrl+Opt+U opens a five line sheet (where we are, decided, open, you promised, they asked of you). Typing `ask <text>` or `wingman ask "..."` answers from the call memory first, then the transcript, then general knowledge; a failed ask always shows a card. `wingman recap` and `wingman followup` print the recap and the follow-up draft. `wingman digest` turns pasted notes and files into people, agenda, facts (each with its source line) and likely questions; without a model the raw text is kept as background. Who a question is for is now decided by the model; the phrase lists are only the offline fallback.
- **Moment engine in the live call (setting `moments.engine`; default `v2`, shown as Live reading, with `legacy` as Classic, the rollback).** With `v2`, every kept line can get help: a strong question asks the model at once, other lines wait in an observer window (6 calls a minute at most). Cards for answers, replies, checks, terms, prompts and notes. Local bank and calc cards show first. A number you say is checked against your notes and the call memory. A soft hourly cap on AI spend (`budget.maxLlmUsdPerHour`) and a calm "AI paused" bar when the AI cannot be used.
- **Moment engine core.** Pure modules in `app/src/moments/`: a tag-first reply parser, a structural intake filter, a frozen question hint, a card scheduler, an observer pacing window and the moment prompt. The bank gets a local 3-gram scorer, so a paraphrase of a card finds it without a model call, and it no longer keeps a global turn language.
- **Memory loop and card pipeline v2 (runs with `moments.engine` = `v2`).** A small model keeps the call memory up to date every 20 s (or at once on a number, a new name, a long-open question, a topic shift or a pause), saves `session.json` after each patch and sends the memory view to the windows. Open questions and promises that nobody picked up give one short PROMPT card. Cards get v2 rows (`kind`, `value`, `why`, `ref`, `closes`, `ctx`), a Check card is never dropped by the per-minute cap, and ratings in `tags.jsonl` tune the thresholds. A model answer with a figure nobody said is replaced by the stall line, in any language. The wrap-up reads the memory (open loops, guarded follow-up draft) and falls back to the transcript summary. Cost: about $0.04 an hour for the updater.
- **Hebrew main window.** The window follows the system language (Settings, Window language can change it). Right-to-left layout, one string catalog per language, a test that both have the same keys.
- **Meeting context.** One optional box on Home: paste text or drop .txt, .md, .pdf (needs pdftotext) or .ics. Long files are cut into parts of about 500 tokens. A meeting never expires and can start the next call too; a crash after Start loses nothing.
- **What Wingman knows** and **So far** panels (sample data in this version): lines can be edited, removed or added, and the exact AI text can be shown.
- **Errors with a next step.** One table of messages; each has a button (Open Keys, Allow microphone, Paste the text instead, ...).
- **Live call loop.** Two audio channels (microphone for you, system audio for the other side through a Core Audio tap) go to two Deepgram Nova-3 streams, so the speaker is always known. A reconnect buffer replays the last two seconds after a dropped connection.
- **Answer cards in about a second.** A question detector that handles English, Hebrew and mixed speech feeds a local answer bank ("Prepared" cards, no AI call) and a Claude Haiku step that skips, stalls, picks a bank card or writes a short answer. AI cards are labelled "not verified".
- **Guards in code.** Deterministic filters for prices, dates and promises turn a risky AI line into a "Buy time" line. House-style never-say rules. Practice mode adds a salary guard and an unclaimed-term guard.
- **Answers for you.** Ask out loud (Ctrl+Opt+A) and get a "For you" card. Arithmetic is computed locally.
- **Call frame and tips.** The call type is detected, a checklist of what the call should cover is kept, and at most one short tip is shown every two minutes.
- **Flow mode.** Several speakers on the other side are told apart; their own discussion is shown muted and answer cards wait; an alert shows when someone turns to you.
- **Practice and prep mode** for rehearsal with your own notes, and an offline **practice call** with a pretend client.
- **Post-call summary** with decisions, next steps, open questions and a follow-up email draft; prices, dates and promises become placeholders.
- **Fact cards** from an optional local snapshot of clients and domains, and copyable capture chips for phone numbers, emails and domains.
- **Degrade ladder and cost caps.** Reduced AI (a slow AI keeps answering; a late answer is dropped), provider switch, bank only, transcript only, with a per-call spend cap (and an amber warning at `budget.warnUsdPerCall`; the cost estimate includes Deepgram add-ons), a circuit breaker and experimental fallback speech providers (Soniox, Gladia).
- **Reliability.** Audio sources restart by themselves; the call survives sleep, stray errors and a full disk; a dead speech channel reconnects or steps down instead of ending the call; if the call folder fails, the call is kept in memory and saved as a rescue copy.
- **Electron menu-bar app** with Home, Calls and Settings (29 options in plain words; the Calls list loads in chunks, so a large history never freezes the menu bar), a guided first-run setup in three required steps (Try it, Connect, Allow) plus an optional "Make it yours", a readiness check, quick calls and prepared meetings, and a separate answer window for the second screen (right-to-left aware).
- **Focus layout for the answer window.** The default shows the other side's line, one big answer and three main keys; a More panel holds the checklist, client card, notes and captured details. The old all-at-once layout stays as `overlay.layout: full`.
- **Self-contained app.** `pnpm dist` builds an unsigned `Wingman.app` and `.dmg` that carries its own engine (no Node, no checkout), with a release workflow for tagged builds. No download is published yet.
- **`wingman` command line** that drives the running app over an owner-only local socket.
- **Installer** (`install.sh`) with check, dry run, update and uninstall modes; it never uses sudo.
- **Swappable pack and profile.** Answer bank, house style and keyterms live in a pack; your name and business live in a profile. Starter packs for sales, support, job-interview practice and an empty pack come in Hebrew and English, and the setup copies one into your folder. `wingman pack from-notes <file>` drafts bank cards from your own notes, FAQ or PDF; every draft goes through the guards, and a card that states a price, date or promise becomes a stall line.
- **Test and QA tooling.** About 1,800 tests in 170+ files, `pnpm eval` with a quality baseline (detector, answer bank, guards) that CI enforces, a synthetic QA harness with 32 invented scenarios, snapshot tools for the windows, and a CI workflow.
- **Diagnostics and internals.** `wingman diagnose` writes one file for a bug report (no transcript or card text); every card records its model and prompt id. Providers are listed in one catalog, audio capture sits behind an `AudioBackend` interface (macOS only so far), and "never use X" source checks are ESLint rules.
- **English and Hebrew.** An English offline demo (`pnpm demo`; `pnpm demo --he` for Hebrew). A call in another language shows a one-time "not supported yet" notice. The English demo and the in-app Practice call also show the call frame, a tip, notes and the summary in English. Status texts, fact cards and the short summary follow the interface language, with a status dot in the answer window and on Home. Summary, notes, tips, frame and self-check follow the call language. Language rules for the detector and the guards live in one module per language (`src/lang/`), so a new language is one file.
- **Documentation.** Architecture, 65 architecture decision records, privacy and security guide, development guide, troubleshooting, pack format and roadmap.

- **A failing AI never leaves an empty screen.** An ask by you (Ctrl+Opt+A) that hits a network, 5xx, 429 or 529 error now shows a short card ("could not get an answer") and the "AI not answering" bar after the first failure. A question from the other side with the same errors shows the "Buy time" line at once (when `reflex.stall` is on) instead of waiting for the stall timer; the bar comes after two failures. Several questions in one final each get their own answer.
- **Speech-to-text opens and reconnects have a time limit.** Every open gives up after 8 seconds (Deepgram, Gladia, Soniox), is retried, and after 30 seconds the call starts anyway with the red bar. A stream that is opened while Stop is pressed is closed. A failed open closes its socket. Audio that was waiting to be replayed is kept if the socket drops again during the replay.
- **The microphone is saved with its name.** The setup window stores the device name next to its number. At every start Wingman checks the name against the plugged-in microphones: if the number moved (a headset connected) the right one is used; if the name is gone, the default microphone is used and an amber bar says so.
- **Texts follow the interface language.** The consent card, the "ask failed" card, the 90 second tip, the reminders, the client proposal, the menu-bar menu and the quit confirmation are in English or Hebrew by `ui.language`. A test keeps Hebrew letters out of the engine source.
- **Stop and quit.** A crash saves the call with the same time budget as a normal stop (sources stop in parallel). Cmd+Q during a call asks first, like the menu item. A call that hangs after it was saved is still ended by the 12 s and 20 s escalation. The practice call writes its sound file in its own private folder. A dead answer-window page stops the 100 ms poll until it is reloaded. A failed start of the engine is reported instead of an uncaught error.

- **Test kit for model behaviour.** A policy fake model, a cassette layer (`WINGMAN_LLM_MODE=replay`), prompt snapshots, a virtual clock and golden-meeting helpers, so model-driven features can be tested with no key and no network. No change for users.

### Fixed

- **The moment and observer calls now read the call memory.** The memory loop learned facts, promises and open questions, but the prompts of the direct and observer calls were built from a copy that only held the pre-meeting notes. They now carry the memory block (`engine/coach.ts` and `engine/moments.ts`).

### Security and privacy

- No telemetry and no cloud account. Audio is never stored.
- API keys are kept in the macOS Keychain. One lookup order everywhere (Keychain, then environment variable, then the legacy `keys.env`), so the source Settings shows is the key a call uses.
- The control socket and call files are owner-only. The app asks for confirmation before a call is started or deleted from the command line.
- Strict Content-Security-Policy in the Electron windows; Electron fuses are set at build time.
- Optional Deepgram model-improvement opt-out (`stt.deepgram.mipOptOut`).

### Known limits

- The full app supports macOS 14.2 or newer only. See [docs/ROADMAP.md](docs/ROADMAP.md).
- English and Hebrew (including mixed speech) are supported; other languages are not supported yet and show a notice.
- Builds are ad-hoc signed, not notarised.
- The .dmg is unsigned and the release workflow has not run yet.
