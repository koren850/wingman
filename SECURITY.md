# Security

Wingman handles call audio, transcripts and API keys. How it treats them is described in [docs/PRIVACY-AND-SECURITY.md](docs/PRIVACY-AND-SECURITY.md).

## Reporting a problem

- For a vulnerability or a privacy problem, use GitHub's private vulnerability reporting: on this repository open the **Security** tab and choose **Report a vulnerability**. This keeps the details private until a fix is ready.
- If that button is not there, open a GitHub issue that says only that you have a security report, with no details, and ask for a private way to send them. Do not describe the weakness in a public issue.
- Never post real API keys, call transcripts, recordings or client data in a report or an issue. Use invented examples.
- This project is maintained by one person. There is no bug bounty and no response-time promise, but reports are welcome.

## Supported versions

Only the latest release (0.0.1 for now) and the latest commit on the main branch.
