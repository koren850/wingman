# Security

Wingman handles call audio, transcripts and API keys. How it treats them is described in [docs/PRIVACY-AND-SECURITY.md](docs/PRIVACY-AND-SECURITY.md).

## Reporting a problem

- For a vulnerability or a privacy problem, open a GitHub issue on this repository, or contact the maintainer through GitHub. If the report would expose a real weakness, say only that you have a security report and ask for a private way to send the details.
- Never post real API keys, call transcripts, recordings or client data in an issue. Use invented examples.
- This is a personal project maintained by one person. There is no bug bounty and no response-time promise, but reports are welcome.

## Supported versions

Only the latest commit on the main branch.
